# Task 1 – Responsive Landing Page

## About the Task
This task is to create a responsive landing page with a fixed navigation menu. The menu changes color when scrolling and when hovering over menu items.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- Fixed navigation bar
- Hover effects on navigation menu
- Scroll-based color change
- Responsive design
